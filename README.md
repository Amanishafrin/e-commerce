# NexaMart (React + Vite demo store)
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
Demo login: demo@example.com / Demo@123  (or register a new demo account)
Deploy: push to GitHub, then Netlify > Add new site > Import from Git. Build command `npm run build`, publish directory `dist`. public/_redirects already handles route refreshes.
